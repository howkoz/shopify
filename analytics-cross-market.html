Key Metrics to Track

Organize tracking by business category to ensure comprehensive cross-market visibility.

Revenue Metrics

Total Sales (by store, market, combined) Gross revenue before deductions
Gross vs Net Revenue After returns, discounts, and adjustments
Average Order Value (AOV) Revenue per transaction by market
Revenue Per Customer Total revenue divided by unique customers
Monthly Recurring Revenue (MRR) Predictable subscription-based revenue

Customer Metrics

New vs Returning Customers Split by market for acquisition vs retention trends
Customer Acquisition Cost (CAC) Marketing spend divided by new customers per market
Customer Lifetime Value (CLV) Expected revenue from customer relationship
Distributor vs Consumer Ratio B2B volume versus DTC transactions
B2B vs DTC Revenue Split Revenue attribution by sales channel

Conversion Metrics

Store Conversion Rate Sessions to orders ratio by market
Cart Abandonment Rate Checkout initiated but not completed
Checkout Completion Rate Percentage of carts converting to orders
Payment Method Success Rates Success rate by payment provider (critical for market issues)
Mobile vs Desktop Conversion Device-specific performance analysis

Operational Metrics

Orders Per Day Volume by market for capacity planning
Fulfillment Time Order to delivery duration
Return Rate Product returns as percentage of orders
Inventory Turnover How quickly inventory moves per location
POS vs Online Sales Ratio Channel mix and growth trends

Google Analytics 4 Setup

GA4 provides deeper user behavior insights that Shopify's native analytics doesn't capture. Configure GA4 to complement Shopify metrics.

Implementation Strategy

Property Setup Create GA4 property per store OR single property with data streams per market for centralized reporting
Installation Method Install via Shopify Customer Events (web pixel) for native integration
Enhanced Ecommerce Enable tracking: view_item, add_to_cart, begin_checkout, purchase, add_to_wishlist, remove_from_cart
Cross-Domain Tracking Configure for tracking users across multi-store domains

Custom Dimensions & Events

Market (market) Distributor ID (distributor_id) Customer Type (customer_type: B2B/DTC) Product Category (category) Inventory Level (inventory_status) Fulfillment Method (fulfillment_type)
Recommended Events: Beyond standard ecommerce events, track subscription starts, subscription cancellations, product reviews submitted, customer support tickets, and store outages for complete operational visibility.

Custom Reporting with Shopify API

For advanced analytics beyond Shopify and GA4, leverage the Shopify GraphQL API to build custom dashboards and data exports.

API & Tools

Bulk Operations API Export large datasets (orders, products, customers) for offline analysis
GraphQL Queries Real-time metrics on orders, customers, products, fulfillments
Data Warehouse Export to BigQuery, Snowflake, or Databricks for advanced analysis
BI Tools Build dashboards in Looker, Tableau, or Power BI for stakeholder viewing

Sample GraphQL Query Pattern

query { orders(first: 100, query: "created:>=2024-01-01") { edges { node { id name totalPrice currencyCode createdAt customer { email totalSpent } } } } }
Cross-Store Analysis: Run the same query against each store API, then aggregate results in a data warehouse for unified reporting across markets with currency normalization.

Currency Normalization

All cross-market reports must normalize to a single currency (USD) for accurate comparison and executive understanding.

Exchange Rate Source Daily rates from Shopify API or ECB for consistency
Reporting Standard Show local currency AND USD equivalent in all reports
FX Impact Tracking Separately attribute revenue variance to market performance vs FX
Budget Management Budget in USD, report in local + USD for clarity
Important: When currency values fluctuate significantly (>5%), separate organic growth from FX impact in executive reports. This prevents misinterpretation of market performance.

Alerting & Monitoring

Establish automated alerts to catch critical issues before they impact business outcomes.

Revenue Alert Daily revenue drop >20% from average → Slack alert + manual investigation
Conversion Anomaly Conversion rate drops below market baseline → Investigate checkout issues
Payment Failures Payment failure rate spikes >5% → Immediate review of payment processors
Inventory Alert SKU falls below safety stock level → Auto-trigger purchase order
Launch Monitoring New market launch: hourly monitoring first 48 hours, then daily for 30 days
Uptime Monitoring Store unavailability or checkout outages → Page incident alert

Configure alerts in Shopify Flow, third-party monitoring tools (Datadog, New Relic), or custom webhooks to your internal systems.
