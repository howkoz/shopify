App Governance & Security

Evaluation framework, approved vendor list, and security policies for Shopify apps across all Unicity stores.

Why App Governance Matters

Each app installed on a Shopify store receives API access to critical store data including orders, customers, and products. Without proper governance, uncontrolled app installations create significant risks:

  • Security Risk: Malicious or compromised apps can access sensitive customer and order data.
  • Performance Degradation: Poorly optimized apps can slow page load times and impact customer experience.
  • Data Leakage: Apps that store data outside Shopify may expose customer information to unauthorized access.
  • Compliance Violations: Non-GDPR compliant apps can expose the business to regulatory penalties.
Key Fact: Plus stores typically average 20–30 installed apps. Each must be evaluated, approved, and monitored throughout its lifecycle.

Evaluation Categories

Security

Data access scope, GDPR compliance, SOC 2 certification, encryption standards

Performance

Page load impact, API call volume, background processing overhead

Reliability

Uptime history, support responsiveness, update frequency and stability

Cost

Monthly subscription fee, per-transaction fees, hidden costs analysis

Integration

API compatibility, webhook support, data export capability

Vendor

Company size, years in business, customer base, industry reviews

App Installation Process

Follow these 10 steps to ensure every app meets security and performance standards before deployment to production:

1

Document Business Need

Identify the specific business problem the app solves. Document the intended use case and expected ROI.

2

Search App Store

Search the Shopify App Store for candidate solutions in the required category.

3

Complete Evaluation Scorecard

Score each candidate using the evaluation framework (Security, Performance, Reliability, Cost, Integration, Vendor).

4

Security Review

Review all requested API permissions and use the security review checklist below. Reject unnecessary access requests.

5

Test in Development Store

Install the app in a development/staging environment. Test all core functionality in a non-production setting.

6

Performance Benchmark

Measure page load time before and after app installation. Document Lighthouse scores and Core Web Vitals impact.

7

Approval from Store Admin

Obtain sign-off from the store administrator confirming the app meets business and security requirements.

8

Install in Production

Install the app in the production store. Plan for installation during a low-traffic period if possible.

9

Configure & Verify

Complete app configuration settings. Test functionality with real production data. Monitor for errors in Shopify logs.

10

Add to App Registry

Record the app in the central registry with install date, owner, and next review date. Set calendar reminder for quarterly review.

App Permission Scopes Guide

Understanding API scopes is critical to app security. Below is a guide to common Shopify app permission scopes and their risk levels:

Permission Scope What It Allows Risk Level
read_products Read product catalog data (titles, descriptions, prices, variants) Low
write_products Modify product data including prices, descriptions, and inventory Medium
read_orders Read order data including customer names, emails, addresses, purchase history Medium
write_orders Create, modify, or cancel orders in the store High
read_customers Read customer PII including names, emails, phone numbers, addresses (GDPR risk) High
write_customers Create, modify, or delete customer records and personal information High
read_all_orders Read ALL historical orders including sensitive order and customer data High
write_script_tags Inject custom JavaScript code into the storefront (potential XSS vector) High
Best Practice: Request the principle of least privilege. Only approve the minimum scopes needed for the app to function. Challenge any requests for write access or customer data access.

Blocked Practices

Do not permit the following practices:

  • Installing apps without completing the evaluation scorecard and security review
  • Granting write_customers scope without documented security review
  • Using apps that modify checkout code directly without Shopify's official checkout APIs
  • Installing duplicate-functionality apps on the same store (consolidate to one vendor per category)
  • Using free/low-cost apps with aggressive user tracking or aggressive data collection policies
  • Installing apps from unverified vendors with no public reviews or clear company information
  • Failing to remove apps within 30 days of identifying they are no longer in use
