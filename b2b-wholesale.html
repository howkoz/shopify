B2B & Wholesale Operations

Managing distributor relationships, custom pricing, net payment terms, and B2B checkout on Shopify Plus

1. B2B on Shopify Overview

▼

Shopify Plus includes native B2B features that provide a complete solution for wholesale operations. These features replaced the legacy Wholesale Channel and are purpose-built for distributor-driven businesses.

Core B2B Capabilities

  • Company Profiles: Create and manage distributor profiles with custom fields and company metadata
  • Custom Price Lists: Up to 25 price lists per company with fixed prices, percentage adjustments, and volume-based pricing
  • Net Payment Terms: Support for Net 15, Net 30, Net 45, Net 60, and custom payment schedules
  • Volume Pricing: Create quantity-based discount tiers (e.g., 1-10 units at price X, 11-50 at price Y)
  • Quick Order Lists: Bulk ordering by SKU for faster purchasing
  • B2B Checkout: Dedicated checkout experience showing company-specific pricing and terms

Deployment Models

  • Blended Store: Single store serving both DTC customers and B2B distributors. Shopify automatically shows different prices and checkout experience based on login status.
  • Dedicated B2B Store: Separate expansion store exclusively for wholesale. Clean separation but requires dual catalog management.
Note: Shopify handles authentication automatically. Distributors log in with their company credentials, and all pricing and terms are applied server-side.

3. Company Profiles (Distributor Management)

▼

In Shopify B2B, each distributor is represented as a "Company" object. Companies are the parent container for pricing, contacts, locations, and custom data.

Company Core Fields

  • Name: Distributor business name (e.g., "ABC Wholesale LLC")
  • Unity ID: Custom metafield linking to distributor ID in Unity ERP
  • Tax Exemption Status: Boolean flag to automatically apply tax exemption at checkout
  • Payment Terms: Default terms (Net 15, Net 30, etc.) assigned to the company
  • Assigned Price List: Primary price list for the company's orders
  • Status: Active, suspended, or inactive

Company Locations

Distributors often have multiple shipping addresses (headquarters, regional warehouses, etc.). Each location is managed separately:

  • Set different shipping addresses per location
  • Configure location-specific inventory (optional)
  • Track orders by location for analytics

Company Contacts

Multiple users can access a single company account:

  • Admin: Full access to company settings, orders, and users
  • Buyer: Can place orders and view order history
  • Viewer: Read-only access to orders and company info

Company Metafields (Custom Data)

Extend the company object with custom fields:

// Example metafields for Unicity distributors { "distributor_rank": "Director", "region": "North America", "upline_distributor_id": "12345", "qualification_status": "Active", "monthly_volume_target": 5000, "previous_month_orders": 12, "credit_limit": 50000 }
Best Practice: Use metafields to store distributor rank, region, upline relationship, and qualification status. This enables dynamic pricing and reporting without modifying the core company object.

4. Price Lists & Tiered Pricing

▼

Price lists are the engine of wholesale pricing on Shopify B2B. Each price list defines prices, discounts, and product visibility for a specific distributor or group of distributors.

Price List Strategies

  • Fixed Prices: Set specific JPY/EUR/USD prices per product per distributor tier
  • Percentage Adjustments: Apply uniform discount percentages across all products (e.g., -20% off retail)
  • Volume-Based Pricing: Quantity breaks where price changes based on order size (1-10 units at $X, 11-50 at $Y, 51+ at $Z)
  • Product Visibility: Show or hide products per price list (e.g., new products only shown to premium tiers)

Recommended Unicity Distributor Tiers

Distributor Tier Discount Off Retail Payment Terms Use Case
Retail / Direct 0% Due on receipt End consumers purchasing directly
Associate -15% Net 15 New distributors, small volume
Manager -25% Net 30 Growing distributors, mid-tier volume
Director -35% Net 45 Established distributors, high volume
Presidential -45% Net 60 Top-tier distributors, strategic partners

Price List Limits & Best Practices

  • Up to 25 price lists per company
  • Create one price list per distributor tier (Retail, Associate, Manager, Director, Presidential)
  • Use percentage adjustments for simplicity (easier to maintain when retail prices change)
  • Use fixed prices for special deals or margin-critical products
  • Test price list changes in a dev environment before pushing to production
Example: Create a "Director Price List" with -35% discount. Assign it to all distributors with Director status. When retail prices change, the discount is automatically recalculated without manual updates.

5. Payment Terms & Credit Management

▼

Payment terms define when and how distributors pay for their orders. Shopify B2B supports flexible payment terms tied to each company or order.

Available Payment Terms

  • Net 15: Payment due 15 days after order
  • Net 30: Payment due 30 days after order (most common for B2B)
  • Net 45: Payment due 45 days after order
  • Net 60: Payment due 60 days after order (premium distributors)
  • Due on Fulfillment: Payment due when order ships
  • Due on Receipt: Payment required before order processing (recommended for new distributors)
  • Cash on Delivery (COD): Payment collected at delivery

Term Assignment Strategy

Assign payment terms based on distributor tier and credit history:

  • New distributors (first 3 orders): Due on receipt or COD
  • Associates: Net 15
  • Managers: Net 30
  • Directors: Net 45
  • Presidential: Net 60

Credit Limit Management

Implement credit controls to minimize risk:

  • Set credit limit per company based on payment history and financial standing
  • Automatic order hold when credit limit exceeded
  • Automatic order hold when payment past due (configurable threshold)
  • Send automatic payment reminders (e.g., 10 days before due date)
  • Configure escalation: reminder → second notice → order hold → account suspension

Payment Processing

Vaulted Payment Methods

Distributors can save payment methods for faster reorders

Draft Orders

Phone/email orders processed by Unicity team with manual approval

Recurring Billing

Set up automatic monthly orders for predictable distributor purchases

ACH/Bank Transfer

Support for direct bank transfers for large orders

Recommendation: Start conservative with payment terms. Begin all new distributors on "Due on Receipt" or Net 15. After 6-12 months of on-time payment, graduate to Net 30. This builds trust while minimizing risk.

6. B2B Checkout Experience

▼

The B2B checkout experience is tailored for distributor buying behavior—fast, bulk-oriented, and integrated with business workflows.

Company-Specific Checkout Features

  • Company-Specific Pricing: Correct tier-based prices shown automatically at cart
  • Payment Terms Displayed: Prominently show payment terms (e.g., "Net 30 - Due April 30, 2026")
  • Purchase Order Number Field: Distributors can add PO number for accounting integration
  • Tax Exemption: Automatically applied for tax-exempt distributors (no tax collected)
  • Company Locations: Select shipping address from pre-configured company locations
  • Billing vs. Shipping: Separate billing and shipping addresses

B2B-Specific Ordering Tools

  • Quick Order: Bulk add products by SKU and quantity in a spreadsheet-like interface
  • Reorder Lists: Favorite or saved orders for repeating monthly purchases
  • Order History: Full access to all previous orders with ability to reorder
  • Draft Orders: For phone/email orders placed through Unicity team (manual approval required)

Draft Orders for Assisted Selling

7. Distributor Onboarding Workflow

▼

This is the step-by-step process to onboard a new distributor from approval to first order:

1
Distributor Approved in Unity System

Unicity distributes unit approves the new distributor in the Unity ERP. Distributor rank (Associate, Manager, Director, Presidential) is assigned based on qualifications and sponsorship.

2
Create Company in Shopify

Unicity operations team creates a Company in Shopify Plus with distributor name, business address, tax ID, and custom metafields (Unity ID, rank, region, upline distributor ID). This can be done manually via Shopify admin or via API integration.

3
Assign Price List Based on Rank

Link the company to the appropriate price list (Associate -15%, Manager -25%, Director -35%, Presidential -45%). This sets wholesale pricing for all products.

4
Set Payment Terms

Assign payment terms (recommended: Net 15 for Associates, Net 30 for Managers, Net 45 for Directors, Net 60 for Presidential). Set credit limit based on expected order volume.

5
Add Company Locations

Configure shipping addresses (headquarters, regional warehouses, etc.). Each location gets its own shipping address and can have location-specific settings.

6
Create Contact & Send B2B Invite

Create the primary contact (usually the distributor owner or manager). Shopify sends an email invite to activate the account and set a password. Can add additional contacts (team members) with different permission levels.

7
Distributor Logs In & Places First Order

Distributor receives email invite, creates password, and logs into Shopify B2B storefront. They see their tier pricing, available products, and can browse, add to cart, and checkout with their assigned payment terms.

8
Verify Order Syncs to Unity ERP

Order is placed in Shopify, inventory is adjusted, and Shopify webhook syncs the order to Unity ERP for fulfillment and accounting. Distributor receives order confirmation and tracking info.

Timeline: Typical onboarding takes 1-2 business days (steps 1-5) plus waiting for distributor account activation (step 6). With automation via API, this can be reduced to same-day turnaround.

8. B2B vs DTC Store Strategy

▼

There are two deployment models for B2B features. Choose based on Unicity's business needs and operational capacity.

Option A: Blended Store (DTC + B2B on Same Store)

Description: A single Shopify storefront serves both direct-to-consumer (DTC) customers and B2B distributors. Shopify automatically shows different prices, checkout experience, and features based on login status.

Blended Store: Pros & Cons

Pros

Single catalog management. Easier to maintain product info, images, and inventory. Lower infrastructure cost. Unified analytics.

Cons

More complex checkout logic. Risk of pricing confusion for DTC if not carefully managed. Harder to customize B2B experience without affecting DTC. Both audiences share the same brand experience.

Option B: Dedicated B2B Store (Expansion Store)

Description: A separate Shopify expansion store exclusively for B2B. DTC customers shop the main store. B2B distributors shop the dedicated B2B store with their own pricing, terms, and checkout.

Dedicated B2B Store: Pros & Cons

Pros

Clean separation. Easier to customize B2B UX without affecting DTC. B2B store can have its own branding, language, and currency. Better for regional segregation.

Cons

Dual catalog management (products, inventory, pricing). Higher operational overhead. Requires syncing between stores. More complex data integration. Higher hosting cost.

Recommendation for Unicity

Phase 1 (Year 1): Start with a blended US store (DTC + B2B). This allows rapid B2B launch with minimal overhead while you validate product-market fit and operational processes.

Phase 2 (Year 2+): Based on B2B volume and regional demand, evaluate dedicated B2B stores for EU and Japan. Separate stores make sense if B2B volume justifies the operational complexity.

Key Decision: Blended is simpler for launch. Dedicated is better for scale. Monitor B2B volume and complexity before deciding.

9. B2B Analytics & Reporting

▼

B2B analytics provide visibility into distributor behavior, pricing, and health. Shopify provides native reporting, and you can extend with Unity ERP integration.

Native Shopify B2B Reports

  • Company Profiles: View all distributors, status, contact info, and associated price list
  • Company Order History: Total orders, spend, and reorder frequency per company
  • Price List Utilization: Which distributors are assigned to each price list
  • Payment Terms Aging: Overdue invoices, upcoming due dates, days-sales-outstanding (DSO)
  • Top Distributors by Volume: Rank by number of orders or total spend
  • Reorder Patterns: Frequency of orders (monthly, quarterly, etc.) per distributor

Custom Reports (via Shopify API)

Build additional analytics by querying the Shopify GraphQL API:

// Example: Get all orders for a company query { orders(filter: "company:XYZ") { edges { node { id createdAt totalPrice lineItems { SKU, quantity, price } } } } }

Unity ERP Integration

Shopify B2B data should sync to Unity ERP for comprehensive distributor analytics:

  • Order Sync: Every Shopify order creates/updates order in Unity
  • Revenue Recognition: COGS, margin, and profitability per distributor
  • Distributor Performance: Compare Shopify metrics (order frequency, average order value) with Unity metrics (volume purchased, commission earned)
  • Inventory Forecasting: Use distributor order patterns to forecast stock needs

Key Metrics to Track

Order Frequency

Orders per month per distributor. Declining frequency may signal churn risk.

Average Order Value (AOV)

Track trends per distributor. AOV growth indicates deeper engagement.

Days-Sales-Outstanding (DSO)

Average days from order to payment. High DSO increases working capital risk.

Product Mix

Which products does each distributor buy? Identify upsell opportunities.

Churn Rate

Percentage of distributors inactive for 90+ days. Early warning of retention issues.

Gross Margin

Revenue minus COGS per distributor. Identify high-margin vs. low-margin customers.

10. API Integration Points

▼

Shopify exposes B2B features via GraphQL API. Use these APIs to integrate Shopify B2B with Unity ERP and custom automation.

Core B2B Mutations (Write Operations)

CompanyCreate / CompanyUpdate

Create or update a company (distributor) in Shopify:

mutation CreateCompany { companyCreate(input: { name: "ABC Wholesale LLC" externalId: "unity-12345" customerSince: "2026-01-15" taxExempt: true }) { company { id name externalId } userErrors { message } } }

PriceListCreate / PriceListFixedPricesAdd

Create a price list and add fixed prices for products:

mutation CreatePriceList { priceListCreate(input: { name: "Director Tier" currency: USD }) { priceList { id name } userErrors { message } } } mutation AddFixedPrices { priceListFixedPricesAdd(input: { priceListId: "gid://shopify/PriceList/1" prices: [ { variantId: "gid://shopify/ProductVariant/1", price: "45.00" } { variantId: "gid://shopify/ProductVariant/2", price: "95.00" } ] }) { priceList { id } userErrors { message } } }

DraftOrderCreate

Create a draft order for phone/email orders placed by Unicity team:

mutation CreateDraftOrder { draftOrderCreate(input: { customerId: "gid://shopify/Customer/1" note: "Phone order from distributor ABC" lineItems: [ { variantId: "gid://shopify/ProductVariant/1", quantity: 10 } ] }) { draftOrder { id invoiceUrl } userErrors { message } } }

Webhooks (Event Subscriptions)

Subscribe to B2B events and trigger downstream actions:

  • companies/create: Triggered when a new company (distributor) is created. Use to sync to Unity ERP.
  • companies/update: Triggered when company details change (tier upgrade, payment terms change). Use to update Unity.
  • orders/create: Triggered when a B2B order is placed. Use to create invoice and sync inventory.
  • orders/fulfilled: Triggered when a B2B order is fulfilled. Use to update distributor in Unity.

Recommended Integration Architecture

Daily Sync Job

Scheduled batch process syncs all distributors from Unity to Shopify B2B (create/update companies and price lists)

Real-Time Webhooks

Shopify webhooks trigger immediate actions: order created → create invoice in accounting, company updated → log in Unity

Manual Overrides

Unicity team can manually adjust company tier, payment terms, or price list in Shopify if needed (e.g., dispute resolution)

Query Examples (Read Operations)

Phase 1: Foundation (Weeks 1-4)

  • Decommission or archive legacy wholesale processes
  • Monitor KPIs (order volume, payment terms compliance, churn)
  • Plan next phase (dedicated EU/Japan stores, advanced analytics)
