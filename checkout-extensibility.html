Checkout Extensibility

Customizing the Shopify checkout experience with UI extensions, Functions, and branding for US, EU, and Japan markets.

Checkout Extensibility Overview

Shopify Plus allows comprehensive checkout customization through multiple tools that replace deprecated checkout.liquid. These tools enable merchants to create branded, personalized checkout experiences while maintaining security and compliance.

Checkout UI Extensions

Visual components sandboxed in checkout. Create custom fields, displays, and interactive elements using React-like components from the Checkout UI components library.

Shopify Functions

Server-side logic for discounts, delivery customization, payment customization, cart transform, and order routing. Replaces deprecated Shopify Scripts.

Checkout Branding API

Customize visual appearance including logo, colors, typography, corner radius, and form field styling. Configure per market for regional branding.

Web Pixels

Track customer interactions and analytics. Supports Google Analytics 4, Meta Pixel, TikTok Pixel, Pinterest Tag, and custom tracking.

Shopify Functions at Checkout

Server-side logic that runs during checkout to modify behavior based on cart contents, customer data, and custom rules. Shopify Functions replace the deprecated Shopify Scripts (retired June 2026).

Function Types

Function Type Purpose Unicity Use Case
Discount Functions Apply product or order-level discounts based on conditions Volume discounts, distributor loyalty discounts, subscription bonuses
Delivery Customization Hide, rename, reorder, or add shipping rates Region-specific shipping options, priority methods first (Konbini in Japan)
Payment Customization Hide, reorder, or rename payment methods Show local payment first (Klarna for EU, Konbini for Japan)
Cart Transform Create bundles, modify line items, add/remove products Auto-add samples when threshold met, bundle recommendations
Order Routing Select fulfillment location based on order data Route to regional warehouse (US, EU, Japan)

Implementation Example: Payment Customization

// Reorder payment methods by region
export function run(input) {
  const { paymentMethods, deliveryAddress } = input;
  const country = deliveryAddress?.country?.code;

  if (country === 'JP') {
    // Move Konbini to top for Japan
    return paymentMethods.sort((a, b) => {
      if (a.name.includes('Konbini')) return -1;
      if (b.name.includes('Konbini')) return 1;
      return 0;
    });
  }

  if (country === 'DE' || country === 'AT' || country === 'NL') {
    // Move Klarna to top for EU
    return paymentMethods.sort((a, b) => {
      if (a.name.includes('Klarna')) return -1;
      if (b.name.includes('Klarna')) return 1;
      return 0;
    });
  }

  return paymentMethods;
}

Checkout A/B Testing

Test checkout variants to optimize conversion rates. Shopify's built-in checkout analytics provide detailed metrics.

Test Variables

  • Button colors: Compare primary color impact on CTA visibility
  • Payment method order: Test which ordering increases payment method acceptance
  • Shipping presentation: Single best option vs. full list of rates
  • Trust badges: Position and visibility of security/trust elements
  • Field layout: Single column vs. multi-column form layouts
  • Upsell placement: Before vs. after payment method selection
  • Subscription offer: Highlight vs. de-emphasize subscription option

Key Metrics to Monitor

Metric Definition Target
Checkout Started Customers who entered checkout Track baseline from top of funnel
Checkout Completed Customers who placed order Increase across variants
Conversion Rate Completed / Started Industry avg 2-5% for B2C, target 5%+
Avg Checkout Time Minutes from start to completion Reduce friction, target 3-5 min
Cart Abandonment Checkout started but not completed Reduce with targeted follow-up
Avg Order Value (AOV) Total revenue / completed orders Increase via upsells/cross-sells
Running Tests: In Shopify Admin, go to Settings > Checkout and create A/B tests with minimum 1-2 week durations. Monitor statistical significance before implementing winners.

Regional Checkout Differences

Configure checkout experiences per market to meet local regulations, payment preferences, and customer expectations.

United States

Key Features:

  • Standard checkout flow: Email → Address → Shipping → Payment
  • Tip option for POS: Optional tip collection after payment (hospitality/services)
  • Address autocomplete: Google Places integration for fast address entry
  • State-specific tax: Auto-calculate sales tax by state/zip code
  • Popular payments: Credit cards, PayPal, Apple Pay, Google Pay, Amazon Pay
  • Shipping: USPS, FedEx, UPS with real-time rate shopping
European Union

Key Features:

  • Required: GDPR consent checkbox: Explicit opt-in for marketing emails and data processing
  • Required: VAT number field: For B2B customers in EU, allow VAT exemption with valid number
  • Country-specific payment methods: Klarna, iDeal (NL), Bancontact (BE), Giropay (DE), PayU (PL)
  • Cookie consent: Full compliance with ePrivacy Directive (cookie banner before tracking)
  • Dynamic VAT calculation: Show VAT separately based on delivery country
  • Shipping: DPD, DHL, GLS with cross-border rates
Japan

Key Features:

  • Postal code → address auto-fill: Reverse of US flow (postal code lookup)
  • Name order (family first): Display "Tanaka Taro" not "Taro Tanaka"
  • Required: Konbini payment first: Convenience store payment (7-Eleven, Lawson, FamilyMart) most popular
  • Required: Furigana fields: Hiragana reading of name for phonetic clarity
  • Phone number format: Validate as +81-XX-XXXX-XXXX
  • Shipping options: Yamato, Sagawa, Japan Post with same-day delivery available
  • Gift wrapping: Common expectation—offer gift wrap option

Web Pixels for Tracking

Install tracking pixels via checkout extensibility to monitor customer journeys, measure conversions, and retarget abandoned carts. All pixels run in sandboxed environment for privacy compliance.

Supported Pixel Types

Google Analytics 4

Track pageviews, conversions, revenue, user properties. Standard for web analytics and ROAS measurement.

Meta Pixel

Track Facebook/Instagram events for retargeting and lookalike audiences. Essential for FB/IG ad performance.

TikTok Pixel

Track TikTok Shop conversions and drive retargeting. Growing importance for Gen Z demographics.

Pinterest Tag

Track pins, conversions, and user interactions. Important for visual commerce and female-skewed audiences.

Custom Pixels

Build custom tracking via JavaScript. Use for internal tools, loyalty programs, or proprietary analytics.

Installation Instructions

  1. In Shopify Admin, go to Settings > Customer events > Custom pixels
  2. Click "Create pixel" and select the platform (GA4, Meta, TikTok, etc.)
  3. Paste the tracking ID or installation code
  4. Choose which events to track (purchase, add to cart, view item, etc.)
  5. Select markets where pixel should fire (US, EU, JP)
  6. Test using Shopify's pixel validator before going live
Privacy Note: Web pixels in Shopify checkout are sandboxed and compliant with GDPR, CCPA, and regional privacy laws. Customer consent is handled via cookie banner and consent management system.

Implementation Checklist

Follow this step-by-step checklist to ensure complete checkout customization rollout across all markets.

Best Practices & Tips

Performance: UI extensions add load time. Lazy-load heavy components and minimize JavaScript bundle size. Test checkout performance metrics on mobile (slower networks).
Mobile First: Over 60% of online purchases are on mobile. Design extensions responsively and test on iPhone/Android before launch.
Regulatory Compliance: EU checkouts require GDPR consent, VAT handling, and payment method compliance. Japan requires furigana fields and correct name ordering. Test with legal before launch.
Accessibility: All extensions must meet WCAG 2.1 AA standards. Use semantic HTML, proper color contrast (4.5:1), and keyboard navigation.
Testing: Use Shopify's development and staging stores. Test all extensions and Functions end-to-end before rolling to production. Place test orders to verify pixel firing.
Deprecated Technology: Shopify Scripts are retired June 2026. Migrate all script-based logic to Shopify Functions before deadline.
