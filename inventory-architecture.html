2Inventory Model Options

Shopify Plus supports multiple inventory management approaches. The right model depends on your product catalog strategy, regional customization needs, and operational complexity.

Shared Catalog, Separate Inventory Recommended

Best for: Unicity's core product strategy

✓ Pros
  • Single product management across all stores
  • Regional inventory control independent
  • Scalable to new markets
  • Lower maintenance overhead
✗ Cons
  • Requires stock allocation strategy
  • Need cross-store replenishment workflow

Separate Catalogs Per Store

Best for: Highly regional product offerings

✓ Pros
  • Full regional isolation
  • Unique product catalogs per market
  • No shared dependencies
✗ Cons
  • Triple the product management work
  • Difficult to maintain consistency
  • Complex integration with ERP

Hybrid Approach

Best for: Unicity's global product mix

✓ Pros
  • Core products shared globally
  • Market-specific variants allowed
  • Balanced flexibility and simplicity
✗ Cons
  • Requires clear catalog segmentation
  • Moderate integration complexity

Unicity Implementation Strategy

Unicity should adopt a Shared Catalog with Hybrid Inventory model:

  • Core Products (All Stores): Feel Great system, nutritional supplements, common wellness products
  • Market-Specific Products: Matcha products (Japan only), regional flavors, localized packaging
  • Inventory Management: Each store/location tracks independent stock levels
  • Fulfillment: Orders fulfilled from nearest warehouse to customer location

3Location Types

Shopify's location system supports multiple fulfillment and inventory models. Each location type has distinct characteristics and operational requirements.

Warehouse

Primary fulfillment center. Ships online orders. Full inventory tracking. Example: US Warehouse, EU Warehouse, Japan Warehouse.

POS Location

Retail or distributor point of sale. Limited inventory allocation. Can receive transfers and stock. Example: MS POS, FL POS.

3PL (Third-Party Logistics)

External fulfillment partner. Managed via fulfillment service integration. Inventory tracked but not directly controlled.

Drop Ship

Vendor ships directly to customer. No Unicity inventory held. Tracked for visibility but fulfillment external.

4Inventory Tracking

SKU Management

Establish a consistent SKU naming convention across all stores for easy identification and cross-location tracking.

UC-[REGION]-[CATEGORY]-[NUMBER] Examples: UC-US-FG-001 (US Feel Great #1) UC-EU-FG-001 (EU Feel Great #1) UC-JP-MT-001 (Japan Matcha #1)

Barcode & UPC Assignment

Assign unique UPC codes to each variant for POS scanning and accurate inventory deduction at retail locations.

Inventory Quantities

Shopify tracks inventory across four dimensions per location:

  • Available: Stock ready to fulfill orders
  • Committed: Stock allocated to unpaid/processing orders
  • Incoming: Stock in transit from supplier/warehouse
  • Damaged: Defective inventory removed from availability

Safety Stock & Reorder Points

Set minimum inventory levels per location to trigger automatic reorder alerts and prevent stockouts.

Example: US Warehouse maintains 500 units of Feel Great System as safety stock. When inventory drops below 500, Shopify Flow triggers an alert to initiate purchase order.

Inventory Adjustments

Manually adjust inventory with documented reason codes to track shrinkage, corrections, and variances:

  • Damage/Loss
  • Found/Recovery
  • Count Correction
  • Inventory Write-Off
  • Audit Adjustment

5Stock Transfers

Intra-Store Transfers

Move inventory between locations within the same store (e.g., warehouse to POS, warehouse to warehouse within US).

  • Process: Create transfer → Pick items → Ship → Receive at destination
  • Tracking: In-transit inventory tracked separately
  • Timeline: Typically 1-7 days depending on distance

Cross-Store Replenishment

Important: Shopify does NOT support direct transfers between stores. Expansion stores (US, EU, Japan) are independent from an inventory perspective.

To replenish across stores, use the purchase order workflow:

  1. Create PO in EU for shipment from US warehouse
  2. Receive goods as incoming inventory at EU warehouse
  3. Update ERP to reflect inter-company inventory movement

Transfer Order Management

Use Shopify's transfer order interface to:

  • View all active and completed transfers
  • Track items in-transit with expected arrival dates
  • Receive partial shipments incrementally
  • Cancel transfers if needed

6Inventory Sync with ERP

Event-Driven Sync

Webhook: inventory_levels/update fires on every stock change, enabling real-time inventory updates to ERP system.

API-Based Updates

Inventory Level Set (POST): Update Shopify inventory from ERP to sync replenishment quantities and correct discrepancies.

POST /inventory_levels/set.json { "inventory_level": { "inventory_item_id": "....", "location_id": "....", "quantities": [{ "name": "available", "quantity": 250 }] } }

Scheduled Batch Sync

Bulk Operations API: Daily reconciliation job to sync large inventory updates efficiently.

  • Reduces API calls and improves performance
  • Ideal for bulk replenishment and transfers
  • Scheduled during off-peak hours

Source of Truth Definition

ERP = Source of Truth for Replenishment Shopify = Source of Truth for Sales Deductions Example: - ERP initiates: "Send 100 units to EU warehouse" → Shopify updated via API - Customer places order: "5 units sold" → Shopify deducts automatically → Webhook fires to ERP

Real-Time vs. Batch Sync

  • Real-Time: Sales order inventory deductions (immediate webhook)
  • Batch: Replenishment orders, inventory adjustments (daily sync job)

7Reorder & Replenishment

Reorder Point Configuration

Define minimum inventory levels per SKU per location. When inventory falls below this threshold, triggering mechanism activates.

  • High-Volume SKUs: Higher safety stock (e.g., 500 units)
  • Seasonal Products: Increased before promotional periods
  • Slow-Moving SKUs: Lower safety stock (e.g., 50 units)

Automated Alert System

Shopify Flow: Create workflows to automatically alert when inventory thresholds are breached.

Example Workflow: IF (Product X inventory < 100 units at US Warehouse) THEN (Send Slack notification to Supply Chain team)

Purchase Order Generation

Create POs manually or integrate with ERP for automated generation:

  1. Flow trigger detects low stock
  2. PO automatically generated in ERP
  3. PO transmitted to supplier
  4. Expected receipt date set in Shopify

Incoming Inventory Management

Track inventory in-transit using transfer orders and purchase receipts:

  • Set expected arrival date
  • Forecast availability based on incoming stock
  • Prepare warehouse for receiving
  • Verify and receive goods upon arrival

Seasonal Adjustments

Adjust safety stock levels seasonally to accommodate demand spikes:

Example: Before summer health season, increase Feel Great System safety stock from 500 to 1000 units at all warehouses. Post-season, revert to normal levels.

8Inventory Reporting

Available Reports in Shopify Admin

Navigate to Analytics > Reports > Inventory for the following insights:

  • Inventory Valuation: Total value using FIFO, weighted average, or LIFO methods
  • Stock by Location: Inventory quantities per warehouse/POS location
  • Days of Supply: Calculate weeks of inventory on hand
  • Slow-Moving Inventory: Products with minimal recent sales
  • Shrinkage Tracking: Expected vs. actual inventory variances

Key Metrics to Monitor

  • Inventory Turnover Ratio: How many times inventory is sold and replaced per period
  • Carry Cost %: Cost of holding inventory relative to sales
  • Stockout Rate: % of orders that cannot be fulfilled due to lack of stock
  • Forecast Accuracy: Comparison of predicted vs. actual demand

Custom Reporting via API

For advanced analytics, export inventory data via GraphQL API for analysis in business intelligence tools (Tableau, Looker, etc.)

9POS Inventory Considerations

POS Location Inventory Model

  • Each POS location receives allocated inventory from parent warehouse
  • Real-time inventory sync between POS system and online store
  • Prevents overselling across channels

Buy Online, Pick Up In Store (BOPIS)

Enable customers to purchase online and pick up at nearby POS location:

  • Requires shared inventory visibility across POS and online
  • Shopify handles inventory reservation automatically
  • POS system receives pickup notification
  • Reduces shipping costs for customers

Distributor POS Management

For distributor locations (MS POS, FL POS):

  • Typically hold smaller inventory quantities
  • Frequent replenishment from warehouse (weekly/bi-weekly)
  • Limited local carrying capacity
  • Higher inventory turnover rate

Cycle Counting Schedule

Implement regular physical inventory counts at POS locations to verify system accuracy:

  • Frequency: Monthly for distributor POS, quarterly for major warehouses
  • Process: Count sample SKUs, verify quantities in Shopify, adjust discrepancies
  • Variance Investigation: Investigate counts exceeding 5% variance

POS System Integration

Ensure POS system is integrated with Shopify for real-time inventory sync:

  • POS sales immediately deduct from Shopify inventory
  • Stock transfers from warehouse reflected in POS system
  • Manual adjustments synced to Shopify within 15 minutes
