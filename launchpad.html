What Is Launchpad

Launchpad is a Shopify Plus-exclusive tool for scheduling time-sensitive events and promotional campaigns. It enables Unicity International to automate and coordinate complex, multi-market campaigns with precision timing and automatic rollback.

Launchpad Automates:
  • Price changes across products and collections
  • Theme switches for event-specific branding
  • Script activation and deactivation
  • Product publishing and unpublishing
  • Inventory visibility and allocation

Each Launchpad event creates a defined start and end window with real-time analytics monitoring during the event. When the event ends, all changes automatically revert to their pre-event state—no manual cleanup required.

Key Capabilities

💲

Price Changes

Schedule price adjustments across products and collections for the event window, with automatic rollback to original pricing.

🎨

Theme Switching

Activate event-specific themes for branded visual experiences, then revert to standard theme automatically.

📦

Product Publishing

Publish or unpublish products at specific times, perfect for coordinated product launches across markets.

⚙️

Script Activation

Activate or deactivate scripts during events. Note: Script management via Launchpad is deprecated as of June 2026.

📊

Real-Time Analytics

Monitor event performance with live revenue tracking, conversion rates, traffic sources, and product performance.

↩️

Automatic Rollback

Everything reverts to pre-event state when the event ends—pricing, products, themes, and scripts all restore automatically.

Launch Strategy Considerations

When scheduling global events, choose one of these approaches:

  • Simultaneous Launch: All markets go live at the same UTC time. Works well for product launches and creates a unified brand moment.
  • Rolling Launch: Start in Japan, then EU 6 hours later, then US 12 hours later. Spreads server load and allows for regional adjustments.
  • Market-Specific Times: Schedule each market for optimal local engagement (morning for US, afternoon for EU, evening for Japan).
Pro Tip: During daylight saving time transitions (March and October), pay careful attention to timezone offsets. CET/CEST changes can affect calculated simultaneous times. Always double-check your Launchpad times 48 hours before the event.

Setting Up a Launchpad Event

Follow these steps to create and schedule a successful Launchpad campaign:

1

Navigate to Launchpad

In your Shopify Admin, go to Apps > Launchpad. You'll see a dashboard with all scheduled events and historical campaigns.

2

Create New Event

Click "Create event" button. This opens the event creation wizard where you'll define the campaign parameters.

3

Event Details

Enter event name (use the naming convention: [MARKET]-[TYPE]-[DATE], e.g., US-FLASH-2026-04-15) and a clear description of the campaign's goals.

4

Set Timing

Define the start date/time and end date/time. Always verify timezone is set correctly. Never leave events open-ended—always specify an end time for automatic rollback.

5

Add Actions

Configure what changes during the event: price adjustments, theme switch, product publishing status, or script activation. You can add multiple actions to a single event.

6

Preview Changes

Review all scheduled changes. This is critical—verify prices, products, and timing are correct before scheduling.

7

Schedule Event

Click "Schedule event" to commit. The event will execute automatically at the scheduled time. You'll receive confirmation and can monitor from the Launchpad dashboard.

8

Monitor Event

On event day, monitor performance in the Launchpad analytics dashboard. Track revenue, conversion rate, and customer response. Have a team member assigned to watch for issues.

Best Practices

Schedule in Advance

Create events at least 24 hours before they go live. This allows time for testing, coordination, and any last-minute adjustments.

Test with Small Set

For new campaign types, test with a small product set first. Once validated, scale to full collection or entire store.

Always Set End Date

Never leave events open-ended. Automatic rollback is a key safety feature—always specify an end date/time so changes revert automatically.

Use Naming Convention

Follow [MARKET]-[TYPE]-[DATE] format (e.g., US-FLASH-2026-04-15) to keep campaigns organized and searchable.

Document in Shared Calendar

Add all scheduled events to a team calendar so stakeholders know about upcoming campaigns and can coordinate marketing activities.

Assign Event Owner

Designate one person per event to monitor during the live campaign. They should watch analytics, respond to issues, and communicate status to the team.

Have Rollback Plan

In case of issues, have a manual rollback process documented. You can manually cancel a Launchpad event from the dashboard if needed.

Coordinate Multi-Market

For global events running across US, EU, and Japan, coordinate start times, messaging, and support across teams. Use a shared campaign brief.

Analytics During Events

Launchpad provides real-time performance data during active events. Monitor these key metrics from the Launchpad dashboard:

💰

Real-Time Revenue

Total revenue generated during the event window. Compare to baseline periods to measure campaign effectiveness.

📈

Conversion Rate

Percentage of visitors who make a purchase during the event. Track against pre-event baseline to assess promotional impact.

🚗

Traffic Sources

Breakdown of where traffic originates: organic search, paid ads, social, email, direct, etc. Helps optimize future promotional spend.

⭐

Top Products

Which products are driving the most revenue during the event. Identify breakout products and bestsellers.

💳

Average Order Value

Compare AOV during the event to normal periods. Indicates whether promotions are driving larger or smaller basket sizes.

👥

Customer Insights

New vs. repeat customer breakdown, geographic distribution, and customer segment performance during the event.

Using Launchpad Analytics for Campaign Optimization

  • Real-time monitoring: Watch metrics during the event to catch issues early and make real-time adjustments if needed.
  • Post-event analysis: Compare event metrics to baseline periods and previous similar campaigns to measure success.
  • Product insights: Identify which products performed best during promotional periods. Use this for future bundle planning.
  • Channel attribution: Track which marketing channels drove traffic to the event. Optimize budget allocation accordingly.
  • Regional performance: For multi-market events, compare results across US, EU, and Japan to understand regional preferences.

Integration with Shopify Flow

Enhance your Launchpad campaigns by automating workflows with Shopify Flow. Here are key integration opportunities:

Slack Notifications

Create Flow automations that send Slack notifications when a Launchpad event starts or ends. Keep your team informed in real-time without manual monitoring.

Example: "When Launchpad event begins, send message to #marketing-alerts with event name, start time, and expected duration."

Order Tagging

Automatically tag orders placed during Launchpad events with the event name. This makes it easy to filter and analyze event-driven revenue in your backend.

Example: "When order is created during Launchpad event 'US-FLASH-2026-04-15', add tag 'event:us-flash-2026-04-15' and 'campaign:flash-sale' to the order."

Post-Event Customer Follow-Up

Trigger email sequences automatically when the event ends. Send thank you emails, product recommendations, or exclusive follow-up offers to event participants.

Example: "When Launchpad event ends, send email to customers who purchased during the event with subject line 'Thank you for your purchase—here's 10% off your next order.'"

Inventory Alerts

Increase inventory alert thresholds during high-demand Launchpad events. Notify your fulfillment team if inventory levels drop unexpectedly during the campaign.

Example: "When Launchpad event 'GLOBAL-LAUNCH-2026-05-01' is active and product inventory drops below 50 units, send alert to #fulfillment-team."

Pro Tip: Set up Flow automations before your event is scheduled. Test them on a small-scale test event first to ensure they work as expected, then enable them for production campaigns.
