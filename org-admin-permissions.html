Organization Admin & Permissions

Role-based access control, user management, and audit procedures for multi-store Shopify Plus operations

Organization Admin Overview

The Organization Admin interface is your centralized management hub for all Shopify Plus stores under Unicity International. This unified dashboard provides complete visibility and control over multi-store operations.

Access Point: admin.shopify.com/store/{org}

Core Capabilities

  • User Management: Add, modify, and remove users across the organization
  • Store Management: Create, configure, and manage multiple Shopify stores
  • Billing & Subscriptions: Manage organization-wide billing, app subscriptions, and plan changes
  • Cross-Store Analytics: View unified reporting and performance metrics across all stores
  • Security Settings: Configure 2FA requirements, IP restrictions, and session management

Organization Roles

Organization-level roles control access to admin functions that span all stores. These roles determine who can manage the organization structure itself.

HIGHEST PRIVILEGE

Organization Admin

Full organizational control

Complete access to:

  • Organization settings & configuration
  • All stores and their settings
  • User management (add/remove/modify)
  • Billing and subscription management
  • Store creation and deletion
  • Activity logs and audit trails

Recommended for: Howard, IT Director

MEDIUM PRIVILEGE

Organization Editor

Store & user management

Can:

  • Manage store configurations
  • Add/remove users from stores
  • Modify user store-level access
  • View analytics

Cannot: Modify org settings, billing, or create/delete stores

Recommended for: Regional managers, operations leads

READ-ONLY

Organization Viewer

Read-only visibility

Access to:

  • Organization analytics dashboard
  • Store list and basic info
  • Cross-store reporting

Cannot: Modify anything, manage users, or access detailed settings

Recommended for: Finance team, executives, analysts

Store Roles

Store-Level Roles

Once a user is assigned to a store, they receive a store-level role that determines their permissions within that specific store.

STORE OWNER

Store Owner

Complete store control

  • All store sections and settings
  • Payment settings and plan changes
  • Billing for this store
  • Store deletion authority

Important: Must be an Organization Admin. One per store.

FULL ACCESS

Full Access Staff

All store sections

  • Orders, Products, Customers
  • Analytics, Marketing, Discounts
  • Content, Apps management
  • Settings (except payments)

Recommended for: Store managers, senior staff

CUSTOM ACCESS

Limited Access Staff

Specific sections only

Granular control per section:

  • Orders (view/edit/manage)
  • Products (view/edit/manage)
  • Customers (view/manage)
  • Analytics (reports only)
  • Marketing, Discounts, Content
SPECIALIZED

POS Only

Point of Sale access exclusively

  • Shopify POS app access
  • In-store transactions
  • Register management

Recommended for: Distributors, field sales reps

REPORTS ONLY

Reports Only

Analytics and reporting

  • View all reports and analytics
  • Export data and reports
  • No transaction or content editing

Recommended for: Finance team, analysts

User Provisioning Workflow

Follow this structured process to add new users to the Unicity organization with appropriate access levels.

1

Determine Role

Identify whether this is an organization-level or store-level role assignment

2

Send Invite

Organization Admin > Users > Add user > Send email invitation

3

Assign Org Role

Set organization-level role: Admin, Editor, or Viewer

4

Configure Store Access

Select which stores and assign store-level permissions

5

Setup 2FA

User accepts invite and sets up two-factor authentication

6

Document Access

Record in access registry with date, role, and approver

Best Practice: Always send invitations from the Organization Admin account. Avoid using personal email forwarding for invites.

Security Requirements

Implement these security controls across all user accounts to protect sensitive business data and comply with regulatory standards.

MANDATORY

Two-Factor Authentication

Required for all staff

  • Enforced via Organization Admin > Settings
  • Supported methods: SMS, authenticator app
  • Recover codes required for backup access
  • No exceptions—enforce on account creation
MONITORING

Login Activity Monitoring

Track all access

  • Settings > Activity log (all staff logins)
  • Review for unusual patterns
  • Flag concurrent login sessions
  • Audit failed login attempts
SESSION

Session Management

Automatic timeout & control

  • Auto-logout after 30 min inactivity
  • Force logout on password change
  • Terminate remote sessions remotely
  • Device trust management
NETWORK

IP Restrictions

Limit access by location

  • Shopify Plus feature (Premium plan)
  • Restrict admin to office IPs only
  • Configure per-user IP whitelist
  • Requires VPN outside office network
API

API Access Tokens

Separate from user accounts

  • Scoped permissions (never full admin)
  • Rotated quarterly minimum
  • Never share across teams
  • Revoke immediately on token leak

Audit Procedures

Maintain compliance and security through regular access reviews and monitoring.

Monthly Review

Tasks:
  • Review all active users in organization
  • Identify and deactivate inactive accounts (30+ days no login)
  • Check for orphaned API tokens
  • Verify 2FA is enabled on all accounts

Quarterly Audit

Full Permission Review:
  • Verify role assignments match current job responsibilities
  • Compare actual permissions against approved matrix
  • Identify excessive access (roles beyond necessity)
  • Document changes and approvals

On Employee Departure

Immediate Deactivation Checklist:
  • Remove from Organization Admin
  • Remove from all store access
  • Revoke all API tokens
  • Change any shared passwords/credentials
  • Audit recent activity for unusual patterns
  • Verify no external data access remained

Activity Log Review

Monitor for suspicious patterns including:

  • Bulk Data Exports: Large report downloads or API data pulls
  • Settings Changes: Unauthorized permission modifications
  • Unusual Hours: Access outside normal business times
  • Mass Deletions: Deletion of orders, products, or customers
  • Payment Changes: Modifications to payment methods or billing
  • User Modifications: Unexpected account changes

Documentation Requirements

Maintain audit trail for all access changes:

  • Date of change
  • User affected
  • What changed (role, permissions, etc.)
  • Who requested the change
  • Who approved the change
  • Business justification

Compliance Considerations

Unicity's multi-region operations require adherence to multiple regulatory frameworks. Configure permissions to ensure compliance.

SOX

Sarbanes-Oxley Compliance

Segregation of Duties

  • Separate order creators from approval authority
  • Refund approvers cannot create refunds
  • Payment processors cannot reconcile
  • Audit all financial transactions
GDPR

GDPR (EU Operations)

Data Protection & Privacy

  • Only EU team accesses EU customer data
  • Use store-level isolation for data boundaries
  • Implement data access logging
  • Support data subject requests (DSR)
PCI DSS

PCI DSS Compliance

Payment Card Security

  • Limit payment settings access to authorized personnel
  • Never expose full card numbers
  • Encrypt payment data in transit/rest
  • Regular security assessments
APPI

APPI (Japan Operations)

Personal Data Protection

  • Similar to GDPR requirements
  • Restrict Japan customer data to JP team
  • Implement access controls
  • Maintain audit trails
Compliance Tip: Document all compliance-driven access restrictions. Review quarterly with Legal and Compliance teams to ensure controls remain current.
