Customer Migration — Unity → Shopify
✓ Done 02/19
🔗 Customers › Import customers › Upload CSV
  • Customers migrated711 Mississippi accounts
  • SourceUnityDBStage.dbo.Customer WHERE market = Mississippi
  • Join key preservedcustom.customer_id metafield = Unity Customer ID
  • Email as universal keyLOWER(LTRIM(RTRIM(Email))) — normalized on both sides
  • Data quality handledLiteral "NULL" strings, whitespace in names, VARCHAR numeric fields
Email is the join key between Shopify orders and Unity customers. Shopify never needs to store Unity Distributor IDs — enrichment happens at Unity import time. This eliminated the round-trip sync architecture entirely.
Order Sync Architecture — Shopify → Unity
✓ Designed & Built

Phase 1 — Manual Daily Process (Launch Feb 21 — ~15–20 min/day)

🔗 Orders › Export › Filter by date › CSV
  • Step 1Export previous day's orders from Shopify Admin (Orders › Export)
  • Step 2VLOOKUP staff name → Unity Distributor ID (10-row mapping table)
  • Step 3SQL: match customer email → UnityDBStage.Customer ID
  • Step 4Build enriched CSV with OrderNumber, DistID, CustomerID, Scenario, SKU, Qty, Price
  • Step 5Send to Bryan Simmons → Unity import
  • Scenario AEmail match + has sponsor → auto-import
  • Scenario BEmail match + no sponsor (orphan) → CSR queue
  • Scenario CNo email match → create new customer in Unity → write ID back to Shopify metafield
